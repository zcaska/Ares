# Project safety rules

- Repository and Git state are authoritative.
- Preserve project constraints and decisions unless the task explicitly changes them.
- Never expose, copy, or persist credentials or secrets into project context or task artifacts.
- Avoid destructive operations unless explicitly required and appropriately authorized by the harness.
- Do not weaken universal clarification, lifecycle, or verification invariants through local configuration.
- Keep changes scoped unless a dependency requires expansion; surface consequential scope changes.
